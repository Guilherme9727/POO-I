## ⭐ Projetos em destaque

### 📚 Sistema de Biblioteca — P2

Projeto desenvolvido em **Java com Swing e MySQL**, organizado em três camadas: `Model`, `DAO` e `UI`.

O sistema trabalha com leitores, funcionários, obras, empréstimos, devoluções e reservas e aplica conceitos mais avançados de POO e persistência.

**Conceitos presentes:**

- herança e classe abstrata;
- polimorfismo;
- associação entre objetos;
- DAO e JDBC;
- interface gráfica com Swing;
- tratamento de exceções;
- transações atômicas e rollback;
- soft delete;
- banco de dados MySQL.

📁 [Abrir Sistema de Biblioteca](./ATIVIDADES/P2)

---

### 🩺 Sistema Clínico — CRUD de agendamento

Sistema de cadastro de **médicos, pacientes e consultas**, construído em Java com interface Swing e persistência em MySQL.

A aplicação está organizada em:

```text
bean  → entidades do domínio
DAO   → acesso ao banco de dados
view  → interface gráfica
```

O projeto inclui Maven, script SQL de configuração do banco e scripts de build para Windows e Linux/macOS.

**Stack:** `Java` · `Swing` · `MySQL` · `JDBC` · `Maven`

📁 [Abrir Sistema Clínico](./ATIVIDADES/P2_Adicional/CRUD_agendamento_clinico)

## 🎯 Objetivo do repositório

Registrar minha evolução em orientação a objetos, desde exercícios introdutórios com classes e objetos até aplicações com interface gráfica, banco de dados e separação em camadas.

## 🧠 Conceitos praticados

- classes e objetos;
- atributos e métodos;
- encapsulamento;
- construtores;
- getters e setters;
- herança;
- polimorfismo;
- classes abstratas;
- associação entre objetos;
- tratamento de exceções;
- DAO e JDBC;
- persistência com MySQL;
- interfaces gráficas com Java Swing;
- divisão de responsabilidades e organização em camadas.

## 📈 Da POO ao Backend

O conteúdo deste repositório mostra uma progressão que vai além de exercícios básicos:

```text
POO básica
classes + objetos + encapsulamento
        ↓
Modelagem de domínio
associação + herança + polimorfismo
        ↓
Aplicações desktop
Swing + DAO + JDBC + MySQL
        ↓
POO II
Spring Boot + API REST + JPA
        ↓
Backend Java
```
